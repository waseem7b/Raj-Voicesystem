# voicsito/call-review/

Durable project state for the call-review subsystem.

| Dir | What lives here | One-file-per |
|---|---|---|
| `checklist/` | The rubric. One YAML per item. | rubric item |
| `sessions/` | Append-only review session notes. | session |
| `changes/` | Every prompt edit. One YAML per edit. | prompt edit |
| `observations/` | Findings that didn't trigger an edit. One YAML per finding. | finding |

Each directory has an `INDEX.md` regenerated by `render.py` — never hand-edit those.
